# 复活甲换装助手（iPhone 网页 App 原型）

这是一个可在 iPhone Safari 中使用的独立辅助工具原型。它提供手动换装步骤、状态记录和简单倒计时，不连接、不读取、不修改《王者荣耀》。

## 当前能做什么
- 显示复活甲换装操作步骤
- 手动记录“未购买 / 已购买 / 已使用或需换装”
- 5、10、20 秒提醒计时
- 深色高对比度、大按钮界面

## iPhone 上使用
### 最简单：本地预览
1. 解压 ZIP。
2. 将 `index.html`、`style.css`、`app.js`、`manifest.json` 放在同一文件夹。
3. 在支持本地 HTML 预览的文件 App/编辑器中打开 `index.html`。某些预览器可能限制 JavaScript。

### 添加到主屏幕（推荐）
要获得较稳定的“像 App 一样”体验，需把这些文件放到一个支持 HTTPS 的静态网页托管服务：
1. 上传这四个文件，保持文件在同一目录。
2. 使用托管服务提供的 HTTPS 地址，在 iPhone Safari 打开。
3. 点“分享” → “添加到主屏幕”。
4. 从主屏幕打开“换装助手”。

注意：单纯的 `file://` 本地文件通常不能完整提供 PWA 安装能力；`manifest.json` 也不会把网页变成原生 IPA。

## 为什么没有 IPA？
iPhone 原生 IPA 需要 Apple 平台的构建与代码签名流程。通常需要 Xcode（在 Mac 上）或受信任的云构建/签名服务，并需要相应 Apple 开发者签名条件。此交付物是可运行的网页 App 原型，不是已签名 IPA。

## iOS 自动点击限制
普通 iOS App / 快捷指令不能随意点击或操控另一个 App（包括游戏）的界面，也不能通过普通网页可靠地向游戏注入点击。本原型不会自动打开游戏商店、出售装备或购买复活甲；游戏操作需要用户手动完成。切换控制的自定手势可在特定条件下重放预先录制的手势，但不保证游戏坐标、界面状态和时序稳定，也不等同于游戏内自动换装宏。

## 文件
- `index.html`：页面结构
- `style.css`：样式
- `app.js`：步骤、状态和倒计时逻辑
- `manifest.json`：网页 App 元数据
